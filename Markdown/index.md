# Markdown

Markdown est un langage de balisage simple, facile à apprendre et à écrire, qui permet de mettre en forme le texte à l’aide de texte brut et de symboles simples.

## Syntaxe Markdown

## Titres

```markdown
# Titre 1

## Titre 2

### Titre 3
```

## Mise en forme du texte

```markdown
**Gras**

*Italique*
```

---

## Listes

### Liste non ordonnée

```markdown
- HTML
- CSS
- JavaScript
```

### Liste ordonnée

```markdown
1. Apprendre
2. Pratiquer
3. Créer
```

---

## Liens

```markdown
[GitHub](https://github.com)
```

---

## Images

```markdown
![Mon image](image.jpg)
```

Utilisez `console.log()`
