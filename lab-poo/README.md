# Lab PHP — Approfondir la programmation orientée objet (POO)

## 1. Besoin du projet technique

Pendant la réalisation de l'architecture de notre projet technique, nous avons besoin d'approfondir plusieurs notions de la programmation orientée objet (POO) en PHP qui ne sont pas encore étudiées dans les tutoriels.

Ces notions sont importantes pour mieux organiser le code, structurer les classes, protéger les données et faciliter la réutilisation du code.

Ce lab est nécessaire pour comprendre ces concepts et apprendre à les appliquer dans notre projet technique.

## 2. Notions et techniques à apprendre

Dans ce lab, nous souhaitons découvrir, comprendre et tester les notions suivantes :

- **Classe abstraite :** comprendre son rôle et apprendre à créer une classe qui sert de modèle pour d'autres classes.
- **Interface :** comprendre comment définir un contrat qui impose des méthodes aux classes qui l'implémentent.
- **Héritage :** apprendre à réutiliser les propriétés et les méthodes d'une autre classe.
- **Polymorphisme :** comprendre comment une même méthode peut avoir des comportements différents selon la classe qui l'utilise.
- **Encapsulation :** apprendre à protéger les données d'une classe en utilisant les niveaux d'accès `public`, `private` et `protected`.
- **Méthodes et propriétés statiques :** comprendre comment utiliser des éléments liés à une classe plutôt qu'à un objet.

L'objectif est de comprendre le rôle de chaque notion, son fonctionnement et son utilité avant de passer à la pratique.

## 3. Réalisation attendue

Créer un exemple pratique en PHP qui regroupe les six notions de la programmation orientée objet dans une petite application liée à notre projet technique.

L'exemple doit :

- Utiliser une classe abstraite comme modèle pour plusieurs classes.
- Définir une interface et l'implémenter dans une ou plusieurs classes.
- Utiliser l'héritage pour partager des propriétés et des méthodes.
- Démontrer le polymorphisme avec une même méthode ayant des comportements différents.
- Appliquer l'encapsulation pour protéger les données.
- Utiliser des propriétés et des méthodes statiques.

Pour chaque notion, fournir :
- Une explication simple de son rôle.
- Un exemple de code fonctionnel.
- Une démonstration de son utilisation.
- Une explication de son intérêt dans le projet technique.

L'exemple doit avoir une structure de fichiers claire et utiliser des situations concrètes liées au projet technique.

**Améliorations :** L'IA peut proposer des améliorations pertinentes ou des notions complémentaires si elles permettent de mieux comprendre la POO et d'améliorer l'exemple pratique. Elle doit cependant respecter les six notions principales demandées.
