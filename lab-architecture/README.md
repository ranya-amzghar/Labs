# Lab : Architecture 3-tiers, DAO, Service et BaseService

## 1. Besoin du projet technique

Dans le projet technique, l'application PHP doit gérer plusieurs éléments, comme les sections, les articles et les journalistes.

Lorsque tout le code est écrit dans les mêmes fichiers, l'application devient difficile à organiser, à comprendre et à maintenir.

Il est donc nécessaire d'apprendre à séparer le code en plusieurs couches pour donner à chaque partie un rôle précis.

Ce Lab permet d'améliorer l'organisation du projet technique, de faciliter la maintenance du code et d'éviter la répétition des traitements.

## 2. Notions et techniques à apprendre

Dans ce Lab, vous devez rechercher, comprendre et tester les notions suivantes :

- **Architecture 3-tiers :** comprendre la séparation entre la présentation, la logique métier et l'accès aux données.
- **DAO (Data Access Object) :** apprendre à séparer les opérations d'accès à la base de données dans des classes spécifiques.
- **Service :** comprendre comment organiser les traitements et les règles métier.
- **BaseService :** apprendre à créer une classe commune qui contient des méthodes partagées entre plusieurs services.

Pour chaque notion, présenter :
- Sa définition et son rôle.
- Un exemple simple en PHP.
- Son utilisation dans le projet technique.

## 3. Réalisation attendue

Créer un exemple pratique en PHP basé sur le projet technique (News Application).

L'exemple doit montrer comment organiser le code en utilisant l'architecture 3-tiers, DAO, Service et BaseService.

Il doit contenir :

- Une structure de dossiers claire.
- Des classes PHP séparées selon leurs responsabilités.
- Un DAO pour gérer l'accès aux données.
- Un Service pour gérer les traitements.
- Un BaseService pour partager les méthodes communes.
- Un exemple de récupération et d'ajout d'une section.

Le code doit être simple, fonctionnel et adapté à un niveau débutant.

Ajouter des explications pour chaque fichier et montrer comment les différentes couches communiquent entre elles.

L'IA peut proposer des améliorations pertinentes à la structure ou au code, tout en respectant les objectifs du Lab et le contexte du projet technique.
